Ludant Support

Help setting up and using the Ludant iOS app.

Set up a controller

  1. Use a compatible ESP32-S3 controller and a USB data cable.
  2. Install Ludant firmware with ESP Launchpad on a Mac or Windows computer using Chrome or Edge, or use the firmware ZIP option.
  3. Power on the controller and keep it near your iPhone.
  4. Open Ludant, choose Set up a controller, then select the nearby controller. Allow Bluetooth access if prompted.

Troubleshooting

  • If no controller appears, check that it is powered on, nearby, and has finished firmware installation, then scan again.
  • If prompted, allow Ludant to use Bluetooth. You can review Bluetooth access in iOS Settings.
  • For browser-based firmware setup, use a USB data cable and Chrome or Edge on a Mac or Windows computer.
